Agentic Evaluations

Agentic evaluations test systems that act over time, use tools, manage state, and recover from failures.

Ordinary Problem

A single QA metric does not show whether an agent can complete a real workflow.

Naive Picture

Evaluate each LLM response independently, as if every message were a standalone answer.

Why It Fails

Agent failures happen across steps: wrong tool call, lost state, repeated loop, weak recovery, or premature stopping.

First-Principles Move

The evaluation unit should match the task unit. For agents, that unit is often a trajectory or completed workflow, not a single message.

What Breaks Without It

Benchmarks overstate capability because they miss long-horizon failure modes.

Course Role

Part 8 focuses on this evaluation shift from isolated answers to trajectories and long-horizon workflows.
