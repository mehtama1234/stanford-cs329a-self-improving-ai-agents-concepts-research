Data Progress

Data progress means model improvement caused by better data, not necessarily by better architecture or optimizer algorithms.

First Principles

Training teaches the model the distribution it sees. If the data shifts from noisy web text to expert demonstrations, synthetic reasoning traces, code, math, and realistic task environments, the learned behavior shifts toward the capabilities people measure.

Concrete Example

A model trained on curated math and code examples can outperform a similarly sized model trained mostly on generic web text.

Why It Matters

Many gains attributed to algorithmic progress may actually come from data curation, data synthesis, filtering, distillation, and benchmark-aligned task design.

Common Misunderstanding

Data progress is not less technical than algorithm progress. Designing data pipelines, verifiers, and task environments is a core engineering challenge.
