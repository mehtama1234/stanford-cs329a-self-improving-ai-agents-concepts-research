RLVR

RLVR is reinforcement learning with verifiable rewards: the model gets rewarded when an answer can be automatically checked as correct.

First Principles

For tasks like math, code, theorem proving, and tool use, correctness can often be checked by rules, tests, execution, or exact answers. RLVR uses those checks as reward signals to increase the probability of successful reasoning trajectories.

Concrete Example

A model generates code. Unit tests pass or fail. Passing trajectories are reinforced; failing trajectories are discouraged.

Why It Matters

RLVR is central to modern reasoning models because it gives scalable feedback without requiring humans to label every step.

Common Misunderstanding

RLVR does not necessarily create brand-new reasoning machinery. It may mostly make successful existing paths more likely.
