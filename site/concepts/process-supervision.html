verification

Process Supervision

Process supervision evaluates intermediate reasoning steps instead of only the final answer.

Ordinary Problem

A final answer can be right for the wrong reason or wrong because of one local step.

Naive Picture

Only the final answer matters because users usually see the final answer.

Why It Fails

Final-answer labels do not tell the model which step was valid, invalid, missing, or unsupported.

First-Principles Move

If reasoning is a chain, feedback should attach to links in the chain. Step-level labels create a denser learning and debugging signal.

What Breaks Without It

Models learn to imitate final-answer style while leaving hidden reasoning errors untouched.

Course Role

Part 3 uses process supervision to explain stronger verification for reasoning.
