agents

The Agent Loop

An agent receives a goal, plans actions, uses tools or environments, observes feedback, tracks memory, and decides when to stop.

Ordinary Problem

Many useful tasks require doing work, not just answering a message.

Naive Picture

An agent is just an LLM with a longer prompt.

Why It Fails

The key difference is interaction. The system must act, observe consequences, update state, and continue toward a goal.

First-Principles Move

A task has state, actions, observations, constraints, and success criteria. The agent loop connects those pieces into a controllable process.

What Breaks Without It

The system gives advice without completing the task, or it drifts because it cannot track progress.

Course Role

This is the core transition from chatbot to agent in Part 1 and the recap.
