Sampling

When an AI model writes its answer one word at a time, it needs a way to pick each new word. Sampling is how it makes that choice. At each step, the model ranks all possible next words by confidence (a score from 0 to 1 that shows how likely each word is). Sampling is the rule for which word it actually picks — sometimes the top choice, sometimes a random pick from the high-scoring ones, sometimes something in between.

First Principles

Here's what happens under the hood. After seeing your question, the model outputs a number for every word in its vocabulary — those numbers tell you the odds of each word being next. Now you need to pick one. The model itself doesn't choose; you do, using a sampling rule. The simplest rule: take the highest-scoring word every time (greedy). A more playful rule: roll loaded dice where each word's weight is its score (random sampling). Between the two: you can turn up the heat on the scores to flatten them (making the model more reckless) or turn down the heat to sharpen them (making it more conservative). You can also trim away words with very low scores before rolling the dice, so the model only considers plausible options.

Concrete Example

You ask the model 'What is 2+2?' At the last step, it has given high scores to '4' (score 0.8), '5' (score 0.15), and 'four' (score 0.03). With a greedy rule, it picks '4' always. With a random rule, it might pick '4' 80% of the time, '5' 15% of the time, and 'four' 3% of the time. If you add heat (increase temperature), those scores spread out flatter — maybe '4' drops to 0.5 and the others rise, so '5' becomes likelier. If you remove heat (decrease temperature), '4' climbs toward 0.95 and the others shrink, making '4' almost guaranteed. On harder reasoning questions, a mix of heat and random sampling lets the model wander through different solution paths instead of always following one worn trail.

Why It Matters

Which sampling rule you use shapes everything about the model's answer. If you always take the top word, the model will follow the same path every time — and if that path leads to a wrong answer, you're stuck. If you use random sampling with the right heat level, the model can explore different reasoning chains. Some paths work; some don't. You can run it many times and pick the best answer. Sampling is not a dial you turn after the model is done — it changes which internal path the model actually follows while thinking, so it changes the final answer itself. For reasoning tasks that need multiple attempts or careful exploration, sampling is the difference between getting stuck and finding a solution.

Common Misunderstanding

Many people think sampling is just a cosmetic choice about formatting or randomness in the output. It's not. For a reasoning task, sampling doesn't just add noise — it determines which problem-solving path the model walks through. Changing sampling can make the model give a completely different answer to the same question. It's not decoration; it's part of the thinking process.
