Inference Budgeting

Inference budgeting is deciding how much runtime compute to spend on a problem and where to spend it.

Ordinary Problem

More samples, deeper search, and more verifier calls can improve quality but cost time and money.

Naive Picture

Always generate as many candidates as possible whenever a problem looks difficult.

Why It Fails

Some tasks are easy, some are hard, and compute spent on low-value branches cannot be spent elsewhere.

First-Principles Move

A system should allocate compute where the expected value of another attempt exceeds its cost. Difficulty estimation, confidence, verifier feedback, and search state guide that allocation.

What Breaks Without It

The agent becomes too slow, too expensive, or still unreliable because compute is spent in the wrong places.

Course Role

This is the operational constraint behind test-time scaling.
