AI Reasoning Concepts, One By One

A standalone sequence for the ideas we discussed around base models, sampling, RLVR, data progress, architecture, and agent evaluation.

#01 · foundation

Pretraining

Pretraining is the broad learning phase where a model predicts the next token (a token is a chunk of text, usually a word or a word-piece) across a huge corpus and absorbs language, facts, patterns, styles, and many weak forms of reasoning.

#02 · foundation

Base Model Capability

A base model is often more capable than one ordinary sample suggests because its probability distribution contains many possible reasoning paths, including rare good ones.

#03 · inference

Sampling

Sampling is the process of choosing tokens from the model's probability distribution during generation.

#04 · inference

Test-Time Compute

Test-time compute means spending more computation when answering a question, without changing the model weights.

#05 · post-training

Supervised Finetuning

Supervised finetuning trains a model on examples of desired input-output behavior.

#06 · post-training

Distillation

Distillation trains one model to imitate another model, usually to transfer capability into a cheaper, smaller, or more specialized model.

#07 · post-training

RLHF

RLHF means reinforcement learning from human feedback, usually used to align model outputs with human preferences.

#08 · post-training

RLVR

RLVR is reinforcement learning with verifiable rewards: the model gets rewarded when an answer can be automatically checked as correct.

#09 · reinforcement learning

GRPO

GRPO is a group-relative RL method that compares multiple answers to the same prompt and rewards answers that are better than the group average.

#10 · reinforcement learning

DAPO

DAPO is a refinement of group-relative RL that focuses training on prompts where the sampled group contains both successes and failures, while also managing exploration and response length.

#11 · evaluation

Pass@1 And Pass@k

Pass@1 measures whether the first answer is correct. Pass@k measures whether at least one of k sampled answers is correct.

#12 · evaluation

Diversity Collapse

Diversity collapse happens when training makes a model repeat a narrower set of output patterns, even if those patterns are often good.

#13 · evaluation

Reasoning Boundary

The reasoning boundary is the set of problems a model can solve at least sometimes under some sampling or inference procedure.

#14 · foundation

Latent Reasoning

Latent reasoning means reasoning behavior that the base model can produce but does not reliably expose under ordinary prompting or decoding.

#15 · interpretability

Mechanisms Versus Heuristics

Mechanisms are reasoning moves the model can perform; heuristics decide when to use them.

#16 · verification

Process Rewards Versus Outcome Rewards

Outcome rewards score the final answer. Process rewards score intermediate reasoning steps.

#17 · verification

Verifiers

A verifier is a system that checks whether an answer, step, action, or trajectory is correct or acceptable.

#18 · data

Data Progress

Data progress means model improvement caused by better data, not necessarily by better architecture or optimizer algorithms.

#19 · data

Synthetic Data

Synthetic data is training or evaluation data generated programmatically, often by another model.

#20 · training

Mid-Training

Mid-training is an intermediate training phase between broad pretraining and final post-training, often used to specialize the model toward important domains or long-context behavior.

#21 · architecture

Mixture Of Experts

MoE models contain many expert subnetworks but activate only a subset for each token.

#22 · architecture

Expert Balancing

Expert balancing keeps an MoE model from overusing a few experts while ignoring others.

#23 · architecture

QK-Norm

QK-norm normalizes query and key vectors in attention to improve training stability.

#24 · architecture

DeepSeek MLA

MLA, or Multi-Head Latent Attention, compresses attention key-value information into latent representations to make long-context inference more efficient.

#25 · optimization

Muon Optimizer

Muon is an optimizer family explored as an alternative or complement to AdamW for more efficient neural network training.

#26 · evaluation

Agentic Evaluations

Agentic evaluations test systems that act over many steps using tools, memory, planning, and feedback.

#27 · agents

Continual Learning

Continual learning is the ability of a deployed system to improve from ongoing experience without forgetting or corrupting previous capabilities.

#28 · inference

Power Sampling

Power sampling is an inference-time method that sharpens the base model's distribution over whole completions rather than retraining the model.

#29 · reinforcement learning

RL Information Inefficiency

RL information inefficiency means RL often gives very little learning signal per unit of compute, especially on long tasks with sparse final rewards.

#30 · forecasting

Algorithmic Progress Categories

Algorithmic progress is not one thing. It mixes architecture, optimizers, systems work, data improvements, distillation, long-context methods, RL, tools, and evaluation design.
