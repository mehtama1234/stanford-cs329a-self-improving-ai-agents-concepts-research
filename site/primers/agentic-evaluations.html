Agentic Evaluations

Agentic evaluations test systems that act over many steps using tools, memory, planning, and feedback.

First Principles

A one-question benchmark measures static answer quality. Agentic tasks measure whether the system can preserve goals, choose actions, use tools correctly, recover from errors, and complete long-horizon work.

Concrete Example

Instead of asking for a code snippet, an agentic evaluation asks the model to inspect a repository, modify files, run tests, debug failures, and finish the task.

Why It Matters

Modern AI systems increasingly fail or succeed as workflows, not as single messages. Evaluation must measure the whole trajectory.

Common Misunderstanding

Agentic evaluation is not just a longer prompt. It requires state, tools, success criteria, and failure analysis.
