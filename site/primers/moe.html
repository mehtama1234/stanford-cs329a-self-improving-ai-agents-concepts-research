Mixture Of Experts

MoE models contain many expert subnetworks but activate only a subset for each token.

First Principles

Dense models spend compute through the whole network for every token. MoE separates total capacity from active compute: the model can have many parameters, but the router selects a few experts per token.

Concrete Example

A model may have hundreds of experts, but for a coding token it routes through code-specialized experts while using only a small fraction of total parameters.

Why It Matters

MoE increases capacity per unit of inference compute, but introduces routing instability, load balancing problems, and expert specialization questions.

Common Misunderstanding

A 600B-parameter MoE model does not necessarily use 600B parameters of compute for each token.
