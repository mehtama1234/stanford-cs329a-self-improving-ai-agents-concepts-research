DAPO

DAPO is a method that teaches a reasoning model to improve itself by picking the right training examples — specifically, prompts where some of the model's attempts worked and some failed. It also manages how long the model's reasoning steps are and how much it should explore different answer paths. By training on examples where the model can see the difference between good and bad reasoning, DAPO helps the model learn which thinking patterns to repeat.

First Principles

When a model learns to reason better, it needs clear signals about what went right and what went wrong. Imagine trying to learn tennis: if every swing you make is terrible, you don't know what to avoid; if every swing is perfect, the game is too easy and you're not learning anything. DAPO stays in the useful middle: it focuses on prompts where roughly half the model's attempts succeed and half fail. This makes the reward signal (the feedback about which reasoning paths are good) clear enough to learn from. It's a form of choosing your training battles wisely — practice the problems that challenge you and teach you the most.

Concrete Example

Suppose the model tries to solve a math problem eight times. Four solutions are correct; four are wrong. That's a perfect example for DAPO to train on, because the model can see the difference between reasoning paths that work and ones that don't. Now suppose instead that all eight attempts are wrong, or all eight are correct. DAPO might skip that prompt or reduce how much it learns from it, because either there's no useful contrast (all wrong), or the problem is already easy (all correct). The model learns fastest when it's in the zone where success and failure are both visible.

Why It Matters

In real reasoning problems, rewards are often sparse — meaning they give feedback only when the model fully solves something, not along the way. DAPO solves two problems at once. First, it filters out unhelpful training data (prompts where the model either fails completely or succeeds completely), so the model spends effort on examples that actually teach. Second, it controls how long the model's reasoning gets and how much it should try different paths, so the model doesn't grow bloated or stuck. This is not just a technical tweak — it's a curriculum, a way of saying 'practice these harder examples first, skip the trivial ones.'

Common Misunderstanding

DAPO does not make reasoning happen by itself. It is not a new thinking capability. It is a filter and a guide that decides which training examples the model should learn from. A model trained with DAPO still needs good initial training (learning from text), still needs a way to check if its answers are right (a verifier), and still needs many attempts to improve. DAPO just makes that improvement smarter by choosing the hardest and most informative examples.
