Domain Reasoning Data

Domain reasoning data is targeted data from areas like math or code where reasoning steps and correctness can be checked.

Ordinary Problem

General text does not provide enough verified examples of hard reasoning.

Naive Picture

More generic internet data is enough because larger corpora should contain more reasoning examples.

Why It Fails

Reasoning-heavy domains need dense examples of structured problems, intermediate steps, and checkable answers.

First-Principles Move

The training data should contain the behavior you want the model to learn. For reasoning, that means problems, rationales, verifiers, and outcomes.

What Breaks Without It

The model imitates reasoning language without reliable reasoning skill.

Course Role

Part 6 uses DeepSeek Math as the case for math-focused reasoning training.
