RLVR

RLVR means teaching a model to get better at reasoning by automatically checking whether its answers are correct. When an answer is right, the model learns that path worked. When an answer is wrong, the model learns to avoid that path next time. The key: the computer can judge correctness itself — no human needed for every single try.

First Principles

Some tasks have built-in test answers. Math has a right result you can compute. Code has unit tests that pass or fail. Theorem proofs can be verified by a checker. Tool use can check whether the tool did what was asked. RLVR treats each of these checks as a report card: if a full attempt (from start to finish) reaches the right answer, boost the odds that the model takes those same steps again. If an attempt fails, lower the odds. The model learns by rewinding its mistakes and strengthening its hits.

Concrete Example

Imagine a model writing a Python function. It tries a solution. A unit test suite runs it: does it handle all the test cases correctly? If yes, the model marks 'that line-by-line path worked' and will favor similar strategies. If no, it marks 'that strategy failed, try something different.' After thousands of attempts, the model has learned which kinds of steps and shortcuts tend to pass the tests.

Why It Matters

Modern reasoning models think step by step — breaking hard problems into smaller pieces. Without RLVR, you'd need a human expert to label every attempt as good or bad, which costs money and time. With RLVR, the computer does the grading automatically (run the test, check the proof, compute the answer). This lets the model improve on billions of attempts without human help. It is the reason reasoning models got powerful enough to solve hard math and coding problems.

Common Misunderstanding

RLVR does not invent new problem-solving tricks. It finds existing good paths through reasoning and makes them more likely. If a model already knows how to think step by step, RLVR tunes which steps it prefers. If the model has never seen a useful strategy, RLVR alone will not create it.
