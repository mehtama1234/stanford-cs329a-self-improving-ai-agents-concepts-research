DeepSeek MLA

MLA, or Multi-Head Latent Attention, compresses attention key-value information into latent representations to make long-context inference more efficient.

First Principles

Long context is expensive largely because models must store and read key-value cache entries for many tokens. MLA reduces that memory burden by representing key-value information more compactly while preserving useful attention behavior.

Concrete Example

A model analyzing a long repository or research corpus can keep more context available without KV-cache costs exploding as quickly.

Why It Matters

MLA is one of the long-context unlockers that changes what tasks are practical at inference time.

Common Misunderstanding

MLA does not make attention free. It changes the memory and compute tradeoff so long context becomes more practical.
