First-Principles Thesis

An AI agent is not just a larger chatbot. Across the playlist, the move from LLMs to agents is a systems move: give the model a goal, let it act through tools, observe feedback, preserve memory, verify intermediate work, and revise until it either completes the task or knows it cannot.

The core pressure is feedback. Scaling gives base capability. Reasoning traces expose intermediate process. Test-time compute samples or searches more paths. Verifiers select, reject, or reward paths. Train-time RL can then use those signals to change future behavior.

Concept Route

From Scaling To Reasoning

The course begins with the old recipe for better LLMs: more compute, more data, and more parameters. It then shifts to methods that make models reason, verify, act, and improve.

Reasoning Traces

A reasoning trace is the visible or supervised path between the problem and the answer: steps, calculations, decisions, tool calls, and justifications.

Test-Time Compute

Test-time compute means spending extra computation while using a fixed model to improve the final answer.

Repeated Sampling And Coverage

Repeated sampling asks the model many times and checks whether at least one attempt solves the problem.

Inference Budgeting

Inference budgeting is deciding how much runtime compute to spend on a problem and where to spend it.

The Verifier Selection Gap

The verifier selection gap is the difference between generating possible answers and knowing which one is correct.

Process Supervision

Process supervision evaluates intermediate reasoning steps instead of only the final answer.

Verifier Robustness

Verifier robustness asks whether the checker itself remains reliable across prompts, tasks, adversarial candidates, and distribution shifts.

Tool Calling

Tool calling lets the model request work from outside itself: search, code execution, calculators, APIs, files, databases, or other services.

ReAct: Reason, Act, Observe

ReAct is a pattern where the model alternates between thinking about what to do, taking an action, observing the result, and continuing.

Execution Feedback

Execution feedback means running generated code or actions and using the result as a correction signal.

Constitutional Self-Critique

Constitutional self-critique uses model-generated critique against a set of principles to improve or filter outputs.

Planning As Search

Planning as search treats an agent's future as a tree or graph of possible thoughts, actions, observations, and next states.

Trajectory Optimization For Agents

Trajectory optimization means improving the whole path an agent takes, not just a single action or final answer.

Train-Time Scaling With RL

Train-time scaling improves the model itself using rationales, rewards, verifiers, and reinforcement learning instead of only spending more compute at inference.

Rationale Bootstrapping

Rationale bootstrapping uses generated or curated explanations to help a model learn better reasoning behavior.

Domain Reasoning Data

Domain reasoning data is targeted data from areas like math or code where reasoning steps and correctness can be checked.

Process Reward Models

A process reward model scores intermediate reasoning steps so training can reward good process, not just good final answers.

Search-Space Curation

Search-space curation is the work of sampling many possible outputs and filtering, clustering, testing, or ranking them into a final answer.

Deep Research Agents

Deep research agents search across sources, decide what is relevant, synthesize evidence, and produce a structured answer or report.

Agentic Evaluations

Agentic evaluations test systems that act over time, use tools, manage state, and recover from failures.

Long-Horizon State And Memory

Long-horizon state and memory are the mechanisms that let an agent remember goals, prior actions, observations, and unfinished constraints over many steps.

The Self-Improvement Loop

The self-improvement loop is the course's central mechanism: generate attempts, get feedback, verify or reward them, and use that signal to improve the next attempt or future model.

Open-Ended Self-Improvement

Open-ended self-improvement lets agents explore new possibilities rather than only optimizing a fixed reward on a fixed benchmark.

The Agent Loop

An agent receives a goal, plans actions, uses tools or environments, observes feedback, tracks memory, and decides when to stop.

Workflow Orchestration

Workflow orchestration is the system design around the model: chains, routers, parallel workers, managers, tools, judges, and verifiers.

Task Specification

Task specification turns a vague user request into a concrete goal, constraints, success criteria, and verification plan.
