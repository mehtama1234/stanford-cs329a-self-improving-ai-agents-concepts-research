Synthetic Data

Synthetic data is training or evaluation data generated programmatically, often by another model.

First Principles

If high-quality real examples are scarce, a model or simulator can generate prompts, answers, reasoning traces, unit tests, tool trajectories, or adversarial cases. The hard part is verifying that generated data is useful and not merely fluent.

Concrete Example

A strong model generates 100,000 coding problems, solutions, and unit tests. Only solutions that pass tests are kept for training.

Why It Matters

Synthetic data enables scale in post-training, but it can amplify bias, cause contamination, or teach imitation without real capability if not verified.

Common Misunderstanding

Synthetic data is not automatically low quality. Verified synthetic data can be extremely valuable; unverified synthetic data can be harmful.
